# Sıfırdan Git ve GitHub Başlangıç Rehberi

Hiç bilmeyenler için temel Git komutlarını ve GitHub iş akışlarını görsel diyagramlarla anlatan kapsamlı Türkçe başlangıç kılavuzu.

## 📚 İçerik Özeti

- **Temel Kavramlar & Kurulum:** Git ve GitHub arasındaki fark, yerel/bulut yapısı ve kimlik ayarları.
- **Commit & Proje Yönetimi:** Projeyi Git'e ekleme, GitHub'a ilk yükleme (`push`) ve güncelleme döngüsü.
- **Branch & Merge Conflict:** Dal açma, paralel geliştirme ve çakışma çözümü.
- **Açık Kaynak Katkısı:** `Fork`, `Clone` ve `Pull Request` (PR) gönderme adımları.
- **Hata Çözümleri:** Sık karşılaşılan terminal hataları ve hızlı başvuru komut tablosu.

## 📥 Kullanım

Depo içerisinde bulunan PDF dosyasını indirerek rehberi doğrudan okuyabilir ve öğrendiklerinizi kendi projelerinizde uygulayabilirsiniz.
