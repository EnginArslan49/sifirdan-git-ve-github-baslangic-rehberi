Hiç bilmeyenler için kurulumdan profesyonel proje yönetimine kadar tüm Git komutlarını ve GitHub iş akışlarını görsel diyagramlar ve gerçek arayüz örnekleriyle anlatan 15 bölümlük kapsamlı Türkçe başlangıç kılavuzu.

## 📚 İçerik Özeti

- **Temel Kavramlar & Kurulum:** Git ve GitHub farkı, temel kavramlar sözlüğü ve Windows/macOS/Linux kimlik yapılandırması.
- **Veri Akış Mimarisi & Commit Standartları:** Görsel veri akış şeması ve `feat:`, `fix:`, `docs:` gibi Conventional Commits ön ekleri.
- **Proje Yükleme & Tüm Branch'lerle Klonlama:** Depoyu GitHub'a ilk kez gönderme (`push`) ve uzak sunucudaki tüm dalları tek seferde yerel bilgisayara çekme.
- **Arayüzle Son Commit'i Düzenleme:** Terminal kullanmadan VS Code, GitHub Desktop ve GitHub Web arayüzü üzerinden son commit mesajını veya dosyalarını güncelleme (`Amend` & `Force Push`).
- **Branch & Merge Conflict Yönetimi:** Paralel dal açma, ana dala birleştirme (`merge`) ve çakışma işaretlerini (`<<<<<<< HEAD`) adım adım çözme.
- **Hata Kurtarma & Zaman Yolculuğu:** `git restore`, `git reset --soft` ve `git revert` ile yanlış değişiklikleri güvenle geri alma karar haritası.
- **Güvenlik & Yapılandırma (`.gitignore`):** Şifreleri (`.env`) ve gereksiz bağımlılık klasörlerini (`node_modules/`, `venv/`) gizlemek için kopyala-yapıştır evrensel şablon.
- **Sürüm Etiketleme (Git Tags & GitHub Releases):** Semantic Versioning (`v1.0.0`) mantığı, `git tag` komutları ve GitHub'da indirilebilir sürüm paketi yayınlama.
- **Açık Kaynak Katkısı (`Fork` & `Pull Request`):** Başkalarının projelerini çatallama, kendi dalında geliştirme ve PR gönderme döngüsü.
- **Hata Çözümleri & Tek Sayfalık Cheat Sheet:** En sık karşılaşılan 8 terminal hatasının çözümü ve masaya asılabilir yazdırılabilir hızlı başvuru kartı.
- **Profesyonel `README.md` & Rozetler:** Markdown biçimlendirme kuralları, **Shields.io** rozet kullanımı ve gerçek GitHub web arayüzü önizlemesi.
